# 01 - 硬件说明

原理图原件：[`BYZT-CANable2.0-Sch-V1.0.pdf`](<../BYZT-CANable2.0资料/01-原理图/BYZT-CANable2.0 Sch V1.0.pdf>)（单页，A4，2024-02-22）。

> 这是 **CANable 2.0 兼容板**，不是官方 Openlight Labs 原版。电路框架一致，但器件选型/接口可能有差异，**以实物丝印为准**。

## 1. 主要规格

| 项目 | 参数 |
|---|---|
| MCU | **STM32G431CBT6**，Cortex-M4F，LQFP48，128 KB Flash / 32 KB SRAM |
| CAN 控制器 | 片内 **FDCAN1**，支持经典 CAN 与 CAN FD |
| USB | USB 2.0 全速（12 Mbit/s），**Type-C 16Pin** 接口 |
| CAN 收发器 | 位号 **U4**，图纸标注 `TJA1050` / `TJA1051T-3` 两种可选 |
| 供电 | USB 5V → **RT9013-33GB** LDO → 3.3V |
| 终端电阻 | 板载 **120Ω**（R7），通过 **P2 跳线** 投入/断开 |
| CAN 接口 | **P3** 3Pin 接线端子：`CAN_H` / `CAN_L` / `GND` |
| 调试接口 | **P4** SWD 4Pin：`3V3` / `SWDIO` / `SWCLK` / `GND` |
| 启动模式 | **P1** BOOT0 跳线（部分批次是按键） |
| 指示灯 | D1 电源指示，D2 `STAT`，D3 `Work` |
| 隔离 | **无隔离**，CAN 侧与 USB 侧共地 |

   └───────────┘                                  │ PA13/PA14 SWD    │

## 3. MCU 引脚占用（按原理图）

| 功能 | 引脚 | 备注 |
|---|---|---|
| FDCAN1_TX | **PB9**（pin 46） | AF9 |
| FDCAN1_RX | **PB8**（pin 45） | AF9 |
| USB_DM | **PA11**（pin 33） | USB_N |
| USB_DP | **PA12**（pin 34） | USB_P |
| SWDIO | **PA13**（pin 37） | P4-3 |
| SWCLK | **PA14**（pin 38） | P4-4 |
| NRST | pin 7 | 复位按键/电容，未引到 SWD 排针 |
| BOOT0 | 启动跳线 P1 | 上电时拉高进入系统 Bootloader（DFU） |

## 4. 电源

- Type-C 只取 5V，CC1/CC2 各 5.1 kΩ 下拉，属于 **UFP（受电设备）**，不支持 PD 快充协商。
- 5V 经 `RT9013-33GB` 得到 3.3V，给 MCU、USB、LED 等供电。
- 图纸里还有一路 **`3V3-CAN`**，由 `Q1 (SI2301) + Q2 (8050)` 组成的开关电路产生，带 22 µF 电容，属于 **3.3V 收发器（TJA1051T-3）选装** 预留。
- 板子 **不带隔离电源**，CAN 地与 USB 地相通。做电机驱动测试时注意共地和地环路。

## 5. CAN 收发器与 CAN FD（重点）

原理图 U4 同时写了两个型号：

| 型号 | 供电 | 最高速率 | CAN FD |
|---|---|---|---|
| **TJA1050** | 5V | 1 Mbit/s | ❌ 不是 FD 收发器，数据段 2M/5M 不可靠 |
| **TJA1051T-3** | 3.3V | 5 Mbit/s | ✅ 支持 CAN FD |

- 图纸中 U4 的 VCC 默认接 **5V**，说明默认 BOM 更像 TJA1050；同时预留了 3V3-CAN 供 3.3V 型号使用。
- **如果你的板子装的是 TJA1050，就不要指望稳定的 2M/5M FD**：MCU 能把 FD 帧发出去，但收发器边沿和环路延迟不满足 FD 要求，容易出错帧。
- 需要 CAN FD 时，先看 U4 丝印；不是 `TJA1051T-3`（或同等级 FD 收发器）就只能跑经典 CAN。

> 有些卖家把 TJA1050 当作“兼容 CAN FD”宣传，这是不严谨的。TJA1050 数据手册只保证到 1 Mbit/s。

## 6. 终端电阻

- 板载 `R7 = 120Ω`，`P2` 短接时接入总线。
- 规则：
  - 总线两端各 120Ω（本板 + 另一个节点/另一端）；
  - 台面临时测试、线很短时，只开一端通常也能通信；
  - 两个 120Ω 并联 = 60Ω，用万用表测 `CAN_H`-`CAN_L` 可判断终端是否正常（断电测）。
- 终端电阻错误是“能发不能收/偶发错误帧”的第一大原因。

## 7. 接口定义

### P3 CAN 端子（3Pin）

| 引脚 | 信号 |
|---|---|
| 1 | `CAN_H` |
| 2 | `CAN_L` |
| 3 | `GND` |

> 官方 CANable 2.0 是 4Pin（多一个 5V 输出），这块 BYZT 板是 3Pin，**没有 5V 输出**，不要按官方图去接 5V。

### P4 SWD（4Pin）

| 引脚 | 信号 |
|---|---|
| 1 | `GND` |
| 2 | `3V3` |
| 3 | `SWDIO` |
| 4 | `SWCLK` |

接 ST-LINK 时注意方向，别把 3V3 和 GND 接反。

### P1 BOOT

短接后上电，MCU 进入 ST 系统 Bootloader，USB 枚举为 `DFU in FS Mode`（VID:PID = `0483:DF11`）。烧录完成后必须断开，再重新上电。

## 8. 与官方 CANable 2.0 的差异

| 项目 | 官方 CANable 2.0 | 本板（BYZT） |
|---|---|---|
| MCU | STM32G431 | STM32G431CBT6 |
| USB | Type-C | Type-C 16Pin |
| CAN 端子 | 4Pin（含 5V 输出） | 3Pin（无 5V） |
| 终端电阻 | 开关/跳线 | P2 跳线 |
| BOOT | 按键 | P1 跳线或按键 |
| 收发器 | TJA1051T/3（FD） | TJA1050 或 TJA1051T-3，看批次 |
| 隔离 | 无 | 无 |

## 9. 上电前检查清单

1. Type-C 线是数据线，不是纯充电线。
2. CAN_H / CAN_L 没接反，GND 已连。
3. 终端电阻设置合理（不要 3 个以上 120Ω 并联）。
4. 总线电压正常（CAN_H ≈ 2.5–3.5V，CAN_L ≈ 1.5–2.5V，隐性时都约 2.5V）。
5. 第一次上电先不接电机/强电，只接 CAN 分析仪验证收发。
