# 上位机与驱动下载

本目录的安装包体积较大，已移到 GitHub Releases：

<https://github.com/anglersking/one_can/releases/tag/v1.0-resources>

| 文件 | 用途 |
|---|---|
| `cangaroo-win32-ccdcb64.zip` | 轻量 CAN 分析软件（推荐，支持 slcan FD） |
| `TSMaster.zip` | 国产 CAN/CANFD 上位机（candleLight） |
| `BUSMASTER_Installer_Ver_3.2.2-cantact.zip` | 开源 CAN 工具（candleLight） |
| `cantact-v0.3.0-alpha.zip` | Java 版 CAN 工具 |
| `jre-8u291-windows-x64.exe` / `i586.exe` | cantact 需要的 Java 运行环境 |
| `cangaroo-master.zip` | cangaroo 源码 |
| `pcan-basic.zip` | cangaroo 的 PEAK PCAN 插件 SDK |

使用说明见本目录 `说明.txt` 和 [`docs/02-windows-quickstart.md`](../../docs/02-windows-quickstart.md)。
