				CAN USB interfaces  --->
					<*> Serial / USB serial CAN Adaptors (slcan)

(2) 用移植好的 can-utils 测试工具来测试 can: （请自行参考网上相关教程移植can-utils）

     ttyACMx 设备映射为 can 设备，比如我这里 ttyACM0 映射为 can0，并设置速率:

	# slcand -o -c -s6 /dev/ttyACM0 can0		(-s6 = 500k  速率为500K)

    可查看到设备（输入命令：ifconfig -a）：

[root@RK356X:/]# ifconfig -a

can0    Link encap:UNSPEC  HWaddr 00-00-00-00-00-00-00-00-00-00-00-00-00-00-00-00  
          UP RUNNING NOARP  MTU:16  Metric:1
          RX packets:3845 errors:0 dropped:0 overruns:0 frame:0
          TX packets:7 errors:0 dropped:0 overruns:0 carrier:0
          collisions:0 txqueuelen:1000 
          RX bytes:0 (0.0 KiB)  TX bytes:0 (0.0 B)

接着可以对slcan0 设备进行操作：

	# ifconfig can0 up				# 启动can0
	# ifconfig can0 txqueuelen 1000		# 配置txqueuelen的传输数据的缓冲区的存储长度

	# cansend can0 999#DEADBEEF   		# can0发送ID为0x999的数据0xdeadbeef
	# candump can0                			# can0接收数据
	# canbusload can0 500000      			# 计算can0上的总线负载百分比
	# cansniffer can0             			# 显示can流量的视图
	# cangen can0 -D 11223344DEADBEEF -L 8    	# 生成固定数据CAN0消息发送,主要用于测试

其中： slcand -o -c -s6 /dev/ttyACM0 can0  命令中的 -s6代表 500速率，其他速率参考：

-s0 = 10k
-s1 = 20k
-s2 = 50k
-s3 = 100k
-s4 = 125k
-s5 = 250k
-s6 = 500k
-s7 = 750k
-s8 = 1M
