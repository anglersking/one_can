
ubuntu下安装 python:

	# sudo apt update

	# sudo apt upgrade

	# sudo apt install python3

	# sudo apt install python3-pip

          查看 python安装是否成功：

	# python3 --version

          安装 python-can 支持：

	# pip install python-can

	如果上面的安装命令不能用，可以试试下面的指定源来安装：

	# pip install python-can --default-timeout=100 -i https://pypi.tuna.tsinghua.edu.cn/simple


安装好 python环境后，直接以下面的方式运行：

# ./can_test.py

# python python-can.py
